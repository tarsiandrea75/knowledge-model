# v0.1.0-alpha Release Notes

`v0.1.0-alpha` is the first internal consumable package for RAG Knowledge Model. It is intended for internal evaluation, onboarding, and consumer feedback. It is not production-ready and does not create or require a git tag.

## Scope

This alpha package includes:

- Schemas: JSON Schema Draft 2020-12 definitions and specialized schemas for the current RKM foundation.
- Fixtures: a minimal fixture package under `examples/fixtures` that demonstrates valid entity, relationship, claim, evidence, and reference structures.
- Seed dataset: a small validated dataset under `data` for early consumer testing and inspection.
- Graph export: a minimal fixture-derived export under `examples/graph-export`.
- Validation commands: a reproducible validation path through `make validate`.
- Documentation: quickstart, changelog, release notes, consumer guide, maturity report, consumability roadmap, and assistant handoff guidance.

## Validation

Run the full repository validation suite from the project root:

```bash
make validate
```

The validation suite checks schema validity, schema prerequisites, schema contracts, registries, fixture instances, data instances, graph export consistency, repository hygiene, unit tests, and documentation relationship usage.

## Pre-Tag Readiness

Before intentionally creating a git tag for this alpha, run the stricter release readiness check from a clean repository:

```bash
make release-check
```

## Graph Export

Regenerate the minimal graph export from fixtures:

```bash
make graph-export
```

The graph export is derived from fixtures and is intentionally small. It validates the first export mechanics and should not be treated as a production graph artifact.

## Non-Goals

This alpha is not:

- A complete catalog of the RAG ecosystem.
- A production-grade graph export.
- A stable public API.
- Ready for broad external adoption.

## Compatibility Expectations

Internal consumers can rely on the current schemas, fixtures, seed data, and graph export as evaluation artifacts for `v0.1.0-alpha`.

The public API and compatibility policy are not stable. Schema fields, registry contents, data layout, graph export shape, and documentation structure may change before a stable release.

## Known Limitations

- The populated dataset is small and does not provide broad RAG ecosystem coverage.
- Fixtures demonstrate only the minimal consumption path.
- The graph export covers the minimal fixture package rather than the full data directory.
- Loader-specific guidance for graph databases, search indexes, vector stores, and JSON document stores is still limited.
- Release packaging exists as documentation only; no git tag is created as part of this alpha documentation update.
- The project remains an internal evaluation package, not a production dependency.

## Next Milestones

- Expand the seed dataset with representative entities, relationships, claims, evidence, and references.
- Add richer fixtures that cover more modeling patterns.
- Extend graph export coverage beyond the minimal fixture-derived contract.
- Define clearer compatibility expectations for future releases.
- Add loader-oriented guidance for common downstream consumption paths.
- Prepare a deliberate release tag only when maintainers decide the package should be tagged.
